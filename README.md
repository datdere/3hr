# 3hrs

1주일에 **나만의 3시간**을 가졌는지 체크하는 간단한 웹 앱입니다.

## 기능 (1단계)
- 이번 주(월–일) 누적 시간과 3시간 목표 대비 진행률
- 남은 시간과 남은 날 기준 하루 페이스 표시
- 빠른 입력: 30분 · 1시간 · 1시간 30분 · 2시간 버튼 한 번으로 오늘 기록 (되돌리기 가능)
- 직접 입력: 이번 주 안에서 날짜와 시간을 골라 기록
- 이번 주 기록 수정·삭제, 지난 주 기록은 잠금
- 지난 8주 달성 여부와 연속 달성 주 수

전체 설계와 다음 단계는 [docs/PRD.md](docs/PRD.md)를 참고하세요.

데이터는 브라우저 `localStorage`에만 저장됩니다(서버 없음).

## 실행
빌드 과정 없이 `index.html`을 브라우저로 열면 됩니다. 로컬 서버로 띄우려면:

```bash
python3 -m http.server 8000
```
